# Bookstore Microservices

## Overview
This project is a microservices-based bookstore application built using Spring Boot.

## Architecture
- API Gateway
- Eureka Server (Service Discovery)
- Config Server
- Multiple domain services:
  - User Service
  - Product Service
  - Order Service
  - Cart Service
  - Wishlist Service
  - Notification Service
  - Feedback Service
  - Customer Details Service
  - Admin Service

## Use Cases
Incrementally implemented using feature branches.
